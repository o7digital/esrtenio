# Estenio — Premium Blue, version 3

Export fidèle de la maquette bleue approuvée.

## Contenu
- index.html : page complète, CSS et JavaScript inclus.
- assets/architecture.webp : visuel architectural conceptuel généré pour la maquette.
- INSTRUCTIONS_CODEX.md : brief de portage vers Astro/React.

## Prévisualisation immédiate
Ouvrir index.html dans un navigateur. Pour servir le dossier localement, depuis ce dossier :

    python3 -m http.server 8080

Puis ouvrir http://localhost:8080 . Arrêter avec Ctrl+C.
Aucune installation ni compilation nécessaire pour cette version HTML/CSS/JavaScript.

## État du projet
Cette archive contient la maquette statique, pas encore un projet Astro/React.
Les sélecteurs de services/profils et le menu mobile sont implémentés.
Le formulaire est une démonstration : aucune donnée n'est envoyée ou conservée.
Le logo typographique est provisoire. Le visuel ne représente pas les locaux d'Estenio.
La démo conserve noindex,nofollow.

Les ressources et ancres ainsi que la syntaxe JavaScript ont été vérifiées. Le contrôle visuel complet et les tests d'interaction navigateur restent à effectuer lors du portage.
